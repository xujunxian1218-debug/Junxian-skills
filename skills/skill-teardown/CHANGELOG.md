# skill-teardown Changelog

## [v0.2.2] - 2026-09-07

### Added
- 终检清单新增 **mermaid 语法自检项**，`references/mermaid-guide.md` 新增「安全写法」节：节点 / 边标签含保留字符（`|` `(` `)` `[` `]` `<` `>` `{` `}`）时整体加双引号——标签含保留字符会让整图在多数渲染器静默不渲染
- 元信息新增条件字段 **「素材域清单」**：批量拆解或同家族多版本素材时，填同域 Skill / 版本清单并逐项标注「本包独有 / 跨包共享」；未提供时，对「其他 Skill / 版本是否存在」的断言一律标 [分析补充]
- 术段新增 **「自由度档位」标注**：每项可复用资产标 高=文字原则（参照改写后用）/ 中=参数化模板（改参数即用）/ 低=照抄资产（原样搬运即可用），复用者一眼判断「怎么拿走」
- 历史卡对照新增两条纪律：**统计数字随注口径**，与预置 / 旧卡数字不一致时先按常见口径（净行数 / ±行数 / diff 总行数 / 字符数）穷举复算再下「不符」结论，数字对照宜多口径并列记账；**改写例核验**——对照中发现原 Skill 示例被改写时，核验新示例仍满足该 Skill 自身明文规则（防「改例改掉正例」）

### Changed
- 卡片模板通用规则三条扩为四条：新增**跨稿 / 跨卡引用统一「源稿名 + 节号」命名空间**——保留被引稿内部节号不改写，整合成稿零改稿嵌入，防整合时引用漂移

## [v0.2.0] - 2026-08-29

### Added
- 逐段产出时的段级硬上限中检：每段落笔前重申该段上限，超限拦在段内，不留给终检兜底
- 「运行时能力探测」角度的命中判别正反例：探测环境能力（命令 / 脚本可用性）才算命中，静态文档发现不算
- 「所属生态」条件字段拆分引用式（主动）/ 被编排（被动）两形态：被动命中记录编排方与调用契约，契约漂移计入一致性风险
- 「无 gate 空标」官方条款：被拆 Skill 未设任何质量 gate 时如实标注并说明影响，不自创分类格式
- 「历史卡对照」条件块：对照注记 ≤200 字统一计数口径、旧卡断链补齐核验、回审建议三档标准写法（条目级 / 章节级 / 整体级）
